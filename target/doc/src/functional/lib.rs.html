3//! This crate implements dependent type equations at runtime, allowing proofs of simple things such as a + b = b + a
4//! 
5//! To convert proofs from another proof language into this language: 
6//! - the function [ctypes::lam_helper] and [ctypes::pi_helper] (and their polymorphic variants) handle de bruijn indexing for you.
7//! - the enum [ctypes::Term::Sig] will serve as the sigma type
8//! - for most normal stuff with equality types, use [equals::straight_eq], [equals::refl], and Axiom J from [equals::EqualTheorems]
9//! - refer to the variants in [ctypes::Term] for more fine control over the proofs
10//! - there is no way to construct inductive types, but many can be constructed by creating a larger type than intended and pruning it by pairing it with an equality that only holds in some cases
11//! - refer to [mod@bool] for an example implementation of this concept.
12//! - use [ctypes::FinalTerm] to finalize a proof and ensure that it is correct - i.e. doesn't rely on lambda parameters that don't exist
13//! - don't write the proofs directly in this language -- translate them!  This is not a proof assistant, and using it as one will be painful.
14//! 
15//! Refer to the the source code of [numbers], [mod@bool], [equals], and [impossible] to see how proofs are constructed in more detail
